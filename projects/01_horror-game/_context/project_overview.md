# 怪異探偵ホラー ── プロジェクト概要（コンテキスト）

## タイトル（仮）
怪異探偵ホラー

## ジャンル
ドット絵風レトロ・サスペンスホラー

## ゲームシステム
- **通常時**: クォータービュー（斜め見下ろし）でのマップ探索
- **調査時**: 特定オブジェクト接近時に「1人称視点」の調査画面へ切り替え

## 演出・特徴
- 暗闇・環境音・懐中電灯による視界制限
- 安易なジャンプスケアに頼らない重厚な雰囲気作り

- Darkwood

## アセット生成ポリシー

### 採用サービス
- **Pollinations API**（登録不要・APIキー不要・利用制限なし）
  - 用途: 画像アセット（スプライト、テクスチャ、背景等）
  - エンドポイント: `https://image.pollinations.ai/prompt/{prompt}`

- **ElevenLabs API**（要APIキー）
  - 用途: 音声アセット（効果音、環境音、ボイス等）
  - キー管理: `.env` ファイルにて `ELEVENLABS_API_KEY` を管理


### 選定経緯
- Imagen 3（Gemini API）は権限制限により404エラーが発生し、自動化が不可能と判断
- Pollinations API は登録・キー不要で安定取得でき、完全自動化を実現できるため採用

### 運用方針
- アセット生成は `scripts/` 以下の Python スクリプトから実行する
- 生成画像は `assets/images/` へ直接保存する
- スプライト・テクスチャはドット絵風レトロスタイルに統一したプロンプトを使用する
- 生成済みアセットは Godot プロジェクトの `godot/resources/` または `assets/` から参照する

### プロンプト基本方針
- スタイル指定: `pixel art, retro horror, dark atmosphere` を必ず含める
- 解像度: 軽量化のため小〜中サイズ（128×128 〜 512×512 程度）を基本とする
